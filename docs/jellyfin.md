# 用 Jellyfin 客户端访问 CineInsight

在「设置 → 手机端浏览 → Jellyfin 客户端连接」设置独立账号、密码和端口，勾选启用后点「应用 Jellyfin 配置」。默认关闭，默认端口 8096；端口占用会显示失败，不会自动换端口。

手机与电脑连接同一局域网。在 Fileball 添加 Jellyfin 服务器，填写设置页显示的局域网地址、账号和密码。电脑必须保持 CineInsight 运行且不休眠。

首期开放视频、标签、作品集、保存视图和常用智能视图。收藏、已看和观看进度写回同一个片库；进度回报不增加播放次数或播放历史账本。多个设备播放同一视频时，以最后到达的进度写入为准，支持向后拖动。源文件缺失、失效、删除或不在配置的扫描范围中时不能读取；没有扫描目录时不开放历史孤儿记录。

仅提供原片直播放及同名外置 SRT，不提供图片库、实时转码、转封装、远程控制或管理接口。客户端提交播放能力时校验容器、音视频编码和码率；能判断的 profile 条件（宽高、码率、音频参数等）按条件校验，未知条件明确返回无法直放。没有技术快照时，在开始播放时调用本地 ffprobe；缺少 ffprobe 会报错，不隐式安装。

字幕保存视图只读现有字幕索引，索引补全仍从桌面发起。标签及作品集作为可浏览文件夹提供；列表每页默认 100，最多 200，支持分页、名称搜索、标签、收藏、已看与可续播筛选。未支持的查询参数返回错误，避免给出错误范围的结果。

HTTP 只接受本机和局域网直接连接；不适用于公网或反向代理部署。密码只保存 bcrypt 哈希，会话令牌仅在进程内保存且最多 64 个、有效期 30 天。重启、关闭或应用配置会撤销所有会话，客户端须重新登录。局域网 HTTP 不加密，请使用独立密码。

## 验证状态

接口测试覆盖登录/失效、访问范围、分页/筛选、原片 Range/HEAD、字幕、播放协商、进度和收藏写回。它们不等于 Fileball 已验收。

Fileball 真机流程尚待执行，需记录客户端版本：登录 → 打开视图和作品集 → 播放 MP4 与 MKV 样片 → 前后 seek → 切换收藏 → 停止播放 → 桌面核对进度与收藏 → 关闭服务确认旧连接失效。另需检查不支持编码、错误密码和文件丢失时的提示。当前环境未连接可操作的 Fileball 手机客户端。

手机网页标签修复有视口事件及组件回归；当前浏览器工具因认证方式不支持未能完成视觉检查，iPhone/Android 软键盘效果仍需真机核对。

开发依据：[Jellyfin 官方登录说明](https://kotlin-sdk.jellyfin.org/guide/authentication.html)、[DeviceProfile](https://typescript-sdk.jellyfin.org/interfaces/generated-client.DeviceProfile.html)、[Fileball 更新记录](https://fileball.app/changelog/)。兼容目标是本页列出的流程，不是完整 Jellyfin 服务端 API。
