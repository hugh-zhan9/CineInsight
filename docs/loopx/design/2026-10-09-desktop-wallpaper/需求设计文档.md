# 桌面壁纸设计

状态：2026-10-09 首版实施合同。原始需求与架构裁定见[概要设计](概要设计.md)。Support lenses：`go-style`（互斥操作、主线程原生对象、退出回收）。

## 架构适配与精确合同

依据：`services/preview_service.go` 只管理预览会话；`services/desktop_notify_darwin.go` 示范 cgo / 主队列；`models/video.go`、`models/image.go` 提供基础尺寸和失效状态；`internal/appdata` 统一数据目录。图片视图缓存与播放代理可能缩小原素材，壁纸不使用它们判断清晰度或作为播放源。

平台边界是 `services/wallpaper_native_darwin.*`，只用公开 AppKit、ImageIO、AVFoundation API；其他平台和无 cgo 构建明确不可用。App 初始化构造服务，shutdown 关闭；进程内互斥串行化设置和停止，Close 后不允许重新设置。没有新增数据库列、迁移或持久播放状态。

<a id="D-WALL-04"></a>
**D-WALL-04 · Interface / Data Contract · 已采用**：新增 Wails 接口：

| 接口 | 输入与输出 |
| --- | --- |
| `GetWallpaperPreflight(kind, mediaID)` | kind 为 `image` / `video`，ID 必须正数。返回 `eligible, reason_code, message, width, height`。不改变桌面，读取元数据和文件可用性。 |
| `SetWallpaper(kind, mediaID)` | 重做预检、平台真实尺寸/可播放检查和源指纹比对。失败返回中文错误，成功返回动态状态。视频启动成功只是完成调度，异步解码结果继续由状态反映。 |
| `GetWallpaperStatus()` | 返回 `supported, state, video_id, display_name, message`，state 为 `idle / starting / playing / paused / failed`。没有活跃视频时 ID 为 0。 |
| `StopVideoWallpaper()` | 幂等移除动态窗口，返回当前状态；不改变已设置的系统图片。主队列未能响应时返回错误并保留会话标识，不能把未停止报告为空闲。 |

失败原因包括 `unsupported_platform`、`invalid_media`、`media_unavailable`、`dimensions_unknown`、`resolution_too_low`、`file_missing`、`file_unreadable`。系统接口与解码错误只向用户显示操作级中文原因，不回传原始绝对路径。平台能力要求 macOS 14+。对合格素材的缩放为保持比例填满桌面，允许裁边。

原生主队列调用尚未开始时两秒后取消，取消后的排队 block 不再执行副作用；已开始的系统调用等待实际结果。AppKit 对象和排队 block 由原生引用计数持有，各入口设自动释放池。退出时服务先禁止新操作，再在主线程释放窗口、播放器和观察者；取消路径覆盖 Wails 主循环退出时后台查询与 shutdown 的互等情况。停止后的迟到唤醒或定时器事件不恢复播放。

静态副本放在应用数据目录 `wallpapers/<sha256><原扩展名>`，单图上限 64 MiB。先写同目录临时文件并同步、校验源的大小/mtime 未变、再发布，之后调用系统接口；不覆盖原图。历史副本保留的理由见 [D-WALL-03](概要设计.md#D-WALL-03)。源视频要求原生可播放，不自动采用已有低清代理。

## 验证与交接

Design Contract Index：[D-WALL-01](概要设计.md#D-WALL-01) 管理边界；[D-WALL-02](概要设计.md#D-WALL-02) 分辨率；[D-WALL-03](概要设计.md#D-WALL-03) 生命周期与失败；[D-WALL-04](#D-WALL-04) 接口与副本。

Verification Strategy：高分辨率图片/视频分别设壁纸；1920×800、1080×1920 与正好阈值通过；1280×720、1920×600、未知尺寸拒绝。源不存在、文件变化、解码不支持时有具体提示；无效替换不影响旧视频。重复停止、切换静态图片、退出均释放窗口。界面须有可见的设壁纸与全局停止入口。桌面播放不得改次数、已看或观看进度。

实施前基线：Go 预览/图片相关筛选测试通过；PreviewDrawer、PhotoLibraryPage、ImageSourceDialog 共 150 项组件测试通过。文档推演中低清在原生调用之前被拒绝，支持素材才进入系统桌面操作。Mermaid 渲染未验证。
