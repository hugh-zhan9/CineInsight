# 日历记录与详情快捷操作

来源：2026-10-29 用户要求点击观看习惯日历查看当天记录；详情支持添加标签、删除视频；标签添加简洁并符合详情页风格。沿用现有回顾、标签和回收站模块，不新增持久化数据或服务。用户未授权提交、推送或安装本批改动。

<a id="D-CAL-01"></a>
## D-CAL-01 日期记录（行为与接口合同）
月历及年度热力图的过去日期、今天可点击，空白/未来不可点击。弹窗展示本机时区该日的视频播放及看图流水，时间倒序、可加载更多；空日显示空状态。沿用日历的播放/看图口径、历史不可用项灰显、现有媒体打开行为。

在 `RecapService.ListRecapItems` 的既有 `RecapListRequest` 添加可选 `date`，只允许 `kind=feed`。日期必须严格为 YYYY-MM-DD，属于请求的月/年/实时窗口且不晚于今天。按当地午夜到次日午夜的半开区间查询；使用 AddDate 保持夏令时自然日。未带 date 的请求行为不变。错误返回 recap_list_date_invalid，旧 period/kind/offset 校验保留。

复用 `RecapCalendar → RecapPage → RecapListDialog → ListRecapItems → recapBuilder.listFeed`。不在前端下载整月再过滤；日期参与请求标识，换日作废旧响应，失败保留重试入口。无数据库迁移，Wails 绑定从 Go 生成。

<a id="D-DETAIL-01"></a>
## D-DETAIL-01 详情动作（行为合同）
标签区保留现有可点击标签，旁边提供轻量“＋ 标签”。搜索已有可手动添加的标签，选中即保存；无同名项可创建并添加。复用 GetAllTags/CreateTag/AddTagToVideo；手动添加自动标签的原有覆盖规则不变。避免重复提交；失败留在浮层并显示错误；成功立刻更新当前标签、管理列表及推荐，创建成功而关联失败时保留创建结果供重试。

删除按钮明确为“从片库移除…”，在 App 挂载现有 PersonMediaDeleteDialog（共享单媒体删除组件），沿用只删记录默认、可选移到废纸篓、失败/取消保留记录、系统不支持废纸篓选择、全局撤销及最近操作。成功后退出被删除的视频详情并刷新片库/首页等已加载投影；撤销宿主不随详情卸载，恢复后重读。不会因选了一个版本而删除其他版本。

详情只发起目标；App 管删除弹窗与跨页刷新，现有删除组件管文件后果与撤销，服务仍是唯一写入者。不开辟第二套删除路径。

## 验证与维护

基线：回顾服务 TestRecap 和回顾前端测试已通过；详情/App/删除组件建立独立基线。覆盖月/年点击、空日/未来、跨日/月份边界、夏令时、分页、旧请求兼容、失败及旧响应；标签搜索/重复/创建后关联失败、详情刷新；删除取消/失败/成功/撤销和目标隔离。生成绑定后检查 diff 和调用守卫。涉及删除入口及 RPC 扩展，最终 exact diff 独立只读审查；无需新增计划文件。具体字段与现有代码入口见[接口细则](需求设计文档.md)。

<a id="D-DETAIL-02"></a>
## D-DETAIL-02 管理入口唯一定位
用户在实现期间补充：名称过滤会命中很多同名数据，应增加路径或其他唯一定位。采用视频 ID，沿用 LibraryFilter（可选 video_id）和现有查询/计数/批量筛选，不新建查询通道。ID 与可见性、其他条件 AND 叠加，正ID不存在时为空，不回退名称搜索；精确定位时关闭版本聚合，仅当前文件。详情仍传文件名用于搜索框显示，但定位期间真实筛选依靠 ID，不受文件重命名影响。

片库展示“当前视频 · 名称”和退出定位按钮（完整路径放 title）；修改关键词/模式、清除条件、跳转其他筛选或应用保存视图时退出定位。临时 ID 不持久化；定位期间不允许保存/覆盖视图，UI 提示先退出，服务端保存校验同样拒绝，避免保存后范围静默扩大。筛选内随机/选中当前结果等消费者仍受 ID 约束。

验证必须覆盖异目录同名、同目录不同文件、非主版本、无匹配ID、计数及旧请求兼容，并覆盖退出定位和保存拒绝。

<a id="D-PHOTO-01"></a>
## D-PHOTO-01 图片删除与精确定位
用户继续追加图片栏位删除和“在图片管理中打开”定位目标。图片浏览网格及大图查看器提供“从图片库移除…”；复用 App 的同一单媒体删除宿主，kind=image，确认与原文件后果、撤销同既有图片删除。取消/失败不关闭查看器，成功移除目标并关闭其大图，图片管理和浏览投影刷新，撤销后重读。

图片管理 locateImage 不再依赖名称及首屏：ImageFilter 可选 image_id，所有定位统一按ID查询，ID等值与原可见性 AND；清除原筛选后仅定位目标并打开其查看器。界面显示可退出的临时目标，改关键词/模式/清除条件退出。ID不存在/不可见时明确提示，不退回同名图片；并发定位只接受最后目标。此筛选进入图片分页、计数与批量操作的同一 DTO，不新增数据库字段。
