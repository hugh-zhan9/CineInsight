# 接口与集成细则

合同索引：[D-CAL-01](概要设计.md#D-CAL-01)、[D-DETAIL-01](概要设计.md#D-DETAIL-01)。本文件仅细化字段与落点，不新增产品裁定。

- `services.RecapListRequest.Date string json:"date,omitempty"`：空值保持旧路径；非空只用于 feed，严格校验日期、本机今天及所属期次，非法返回 `ErrRecapListDateInvalid`。分页 total/has_more 在日范围计算，Limit 保持 60 默认、200 上限。
- `RecapCalendar` 的 `select-day` 输出原始 day bucket，含 date/plays/views；按钮支持原生键盘操作，并用日期/次数作为可访问名称。`RecapPage` 记录选中日期传给现有列表弹窗，弹窗标题为日期及观看记录数量；显示具体播放时刻，媒体打开规则不变。
- 轻量标签组件拥有临时搜索与保存状态，成功输出 `{videoId, tag}`；详情更新标签并发 `video-state-changed`，App 重读全局标签。仅展示与 AddTagDialog 相同的手动可加集合，已关联项不重复列出。
- 详情 `delete-video(video)` 交给 App 的单一删除目标，App 中 PersonMediaDeleteDialog 复用既有 `deleted(target)` / `restored({kind,ids})` 回调。仅删除成功且当前仍展示目标时返回来源；失败及取消不导航。恢复可在组件卸载后回调 App，按当前数据源刷新。

- [D-DETAIL-02](概要设计.md#D-DETAIL-02)：LibraryFilter.VideoID uint `json:"video_id,omitempty"`，非零为 videos.id 等值，清除 CollapseVersions。VideoListPage 临时 focusedVideo 进入 currentLibraryFilter，定位时关键字仅作显示，不叠加名称条件。applyVideoTargetCommand 清理旧条件后设置目标；Apply saved view/模式切换/关键词变化/清空条件退出定位。buildSavedLibraryView 对 VideoID 非零请求拒绝，字段不落保存视图模型。

- [D-PHOTO-01](概要设计.md#D-PHOTO-01)：ImageFilter.ImageID uint `json:"image_id,omitempty"`，applyImageFilter 同可见性叠加ID等值。PhotoLibraryPage.focusedImage / buildFilter / locateImage 使用ID并由定位代际拦截旧请求；PhotoBrowsePage 与 PhotoLightbox 的 delete-image(image) 交给 App 共用删除目标。成功回调按 kind 分流，不将图片ID传给视频路径。
