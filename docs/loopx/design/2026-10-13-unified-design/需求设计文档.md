## 3 交互规则落点

<a id="rules"></a>
- **删除（D-UD-07/08）**：
  - 「移到废纸篓」：统一走现有删除宿主（`TrashUndoBanner` 的 `runDelete`）。完成后用 `notifyUndo`，撤销调用现有的恢复接口；页内的 `TrashUndoBanner` 撤销条改为全局提示，宿主逻辑不变。
  - 「从片库移除」：用 level `confirm`。
  - 永久删除、清除失联记录、清空目标库：用 level `irreversible`，输入的就是按钮上的文字。
  - 迁移清单：`utils/lostMedia.js` 的「清除记录」、`TrashCenterDialog` 的「移除记录」、`DatabaseSection` 的「清空」。
- **撤销入口（D-UD-09）**：任务中心新增「最近操作」页签，前端内存里留最近 20 条可撤销操作（删除批次、元数据批量编辑）。删除批次用现有 `RestoreTrashBatch`，批量编辑用现有 `UndoMetadataBatchEdit`。不新增后端存储，重启后清空，并说明这一点。
  - 生产方一律调 `utils/feedback.js` 的 `notifyUndoable(message, undo, { label })`：同时记进「最近操作」（`utils/recentOperations.js`）并出带「撤销」的全局提示；两处是同一条记录，从哪边撤销都只执行一次，成功后记录移除。只要提示、不该进「最近操作」的才用 `notifyUndo`。
- **选择（D-UD-10）**：用 `SelectionBar` 替换以下各处，并改掉「不选等于全选」：
  - 片库 `BatchActionBar`；
  - 图片库的常驻选择工具；
  - 存储体检的「全选已列出的」；
  - 清理两处的勾选操作；
  - 失联页的「不选等于全选」（`LostMediaPanel.vue:67`）。
- **任务反馈（D-UD-11）**：
  - 收进任务中心：片库页的 `BackgroundTaskStatusBars`、`IncrementalScanBar`、`SemanticNoticeBar` 三条，以及图片库的 `image-task-bar`。
  - 页内只保留本页正在做的一件，用 `ProgressBar`。
  - 顶栏的任务按钮改为任务指示。
- **快捷键（D-UD-03）**：
  - ⌘K 与 ⌘⇧P 打开命令面板；⌘⇧K 打开清理中心。
  - `VideoListPage` 自己接 ⌘K 的分支（`cleanupHotkey`）改为接 ⌘⇧K。
  - 快捷键帮助列全：⌘K、⌘⇧K、⌘F、⌘R、⌘T、⌘⇧N、Esc、Space、列表方向键，字幕编辑的 ⌘S / ⌘Z / ⌘⇧Z / ⌘F，以及图片查看器的 ← / → / F。
  - 面板没开时，别的对话框（`role="dialog"` / `aria-modal="true"`）或应用内确认框开着，⌘K 与 ⌘⇧P 不响应；面板开着时再按关掉。Esc 只关最上面一层对话框（`BaseModal` 按打开先后入栈）。

## 5 守卫测试（D-UD-15）

<a id="guards"></a>
新增 `frontend/scripts/design-system.test.mjs`（`npm test` 里运行）。每条规则带一份待迁移清单（`scripts/design-system-pending/` 下按负责组分文件），按文件记还剩几处违规，是棘轮：不在清单里的文件出现违规、或处数比清单多都失败；处数比清单少也失败，提示把数字降到实际值；清零后要删掉这一项。第 0 步结束时清零：

1. `.vue` 与 `.css`（`styles/tokens.css`、手机端 `short-feed/` 除外）里不许出现颜色字面量，只能用 `var(--…)`：hex，`rgb()` / `hsl()` / `hwb()` / `lab()` / `lch()` / `oklab()` / `oklch()`，颜色属性里的 CSS 颜色名（`transparent`、`currentColor` 与全局关键字除外），模板 `:style` 对象里 `color` / `background` 的其他字面量。
2. `font-size` 只能用 `var(--fs-*)`；`font-weight` 只能用 `var(--fw-*)` 或 400 / 500 / 600 / 700；`font:` 简写里不许带 px 字号；`:style` 对象里的 `fontSize` 同样只能用 `var(--fs-*)`。
3. `z-index`（含 `:style` 对象里的 `zIndex`）只能用 `var(--z-*)`、`auto`、-1 到 3 的局部叠放。
4. 引用的每个 CSS 变量都必须在 `tokens.css` 里有定义。
5. 模板的 class 绑定（静态或 `:class`）里不许出现 `modal-overlay` 的自制遮罩；所有 `BaseModal` 用法（含 `<base-modal>` 写法与改名注册）改为 `DialogShell`（`BaseModal` 只允许 `DialogShell` 内部使用）。
6. 顶层页面组件（`APP_NAV` 列出的各页）根部必须有 `PageHeader` 或 `HeroHeader`。
7. 用词：模板文本里不许出现第 4 节的旧词（「...」、「选择本页」、「打开所在目录」等）。

`unstyledControls` 同步收紧：按钮必须带 `.btn` / `.btn-link` / `.btn-icon` 之一，或是组件内部的已登记例外；它的待迁移清单（同一批 JSON 里的 `buttons`）按同一棘轮检查。
