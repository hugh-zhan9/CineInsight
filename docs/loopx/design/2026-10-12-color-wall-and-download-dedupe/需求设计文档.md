## 下载完自动查重

### 流程与归属

- `BrowserDownloadDeps` 新增 `CheckDuplicates func(ctx, task BrowserDownloadTask) (DownloadDuplicateResult, error)` 与 `Notify`；`run()` 在把任务写成 `done` 并推送之后，把任务 ID 投进查重队列（单 goroutine 消费，进程退出时随服务停止）。依赖由 App 注入，下载服务只认函数签名（[D-DD-05](概要设计.md#D-DD-05)）。
- 查重实现 `DownloadDuplicateChecker`（`services/download_duplicate.go`）：
  1. 精确：`os.Stat(output_path)` 取大小 → 在可见视频里找同大小、ID 不同的候选 → 对新文件与候选各算 `getPartialHash` → 相同即「相同文件」。
  2. 近似（仅 `video_id ≠ 0`）：对新视频调用 `PerceptualHashService.Refresh` 得到指纹 → 读取可见视频中有当前指纹、时长可比（`perceptualDurationsComparable`）的行 → `perceptualRowsMatch` 命中且不在 `NearDuplicateDismissal`（指纹仍有效）里的，记为「其他版本」。已经算作「相同文件」的不重复列。
  3. 关系标注：按像素数比较——对方像素多 ≥ 5% 为 `higher`，少 ≥ 5% 为 `lower`，否则按大小记 `smaller` / `larger` / `similar`。
  4. 覆盖：近似比对时附带「片库里还没算指纹的可见视频数」。
- 失败（文件不可读、ffmpeg 出错、超时 2 分钟）只记 `error`，不重试，下载状态不变。

### 数据与接口合同

- `browser_download_tasks` 新增 `duplicate_result text not null default ''`：空表示未查或进行中；否则为 JSON：

```json
{ "status": "found|none|failed|skipped", "checked_at": "RFC3339",
  "matches": [{ "video_id": 12, "kind": "exact|version", "relation": "same|higher|lower|larger|smaller|similar" }],
  "unhashed_videos": 34, "error": "" }
```

  `skipped`：文件已不在、或任务没有输出文件。
- `BrowserDownloadTask` DTO 新增 `duplicate: { status, matches: [{ video_id, kind, relation, title, width, height, size }], unhashed_videos, error }`；`title/width/height/size` 读取时按 ID 现查，对方已删除或不可见的匹配不返回。
- 新增 App 方法：`DismissDownloadDuplicate(taskID, videoID)`——写 `NearDuplicateDismissal`（仅 `version` 匹配）或只从该任务结果里移除（`exact` 匹配，相同文件不写全局忽略）。删除这次下载走既有 `DeleteVideosWithResult`（需要 `video_id ≠ 0`）；建立版本组走既有 `CreateVersionGroup`；对比播放打开清单 F 的对比播放器。
- 通知：有匹配时 `notifyDesktop("下载的《X》片库里已有", "相同文件" / "其他版本")`，不含路径；应用内由下载页根据推送显示提示块。

## 验证与交接

### Verification Strategy

源没有 TC 编号，以下按会话裁决的场景列出；全部为待实现后执行的自动化检查（Go 双后端：SQLite 与 `CINEINSIGHT_TEST_PG_DSN`；前端 vitest）。

| 场景 | 预期 | 覆盖决定 |
|---|---|---|
| 下载了片库已有的同一文件 | 结果为 exact/same，下载页提示，后台时发通知 | D-DD-01、D-DD-02、D-DD-04 |
| 下载了同一部的 720p，片库已有 1080p | 结果为 version/higher；忽略后不再提示 | D-DD-02、D-DD-04 |
| 下载目录不在扫描根 | 只做精确比对 | D-DD-01 |
| 查重出错 | 下载仍为完成，结果 failed 带原因 | D-DD-01 |
| 重启应用 | 历史任务仍显示查重结论；对方已删的匹配不显示 | D-DD-03 |

文档推演：取「下载目录不在扫描根」走查重——`video_id = 0`，只做大小 + 采样哈希；找到同文件时提示块出现，但「移到废纸篓」不可用（没有片库记录），只提供「打开所在目录」。此限制需在实现时于提示块中写明。

呈现检查：查重时序图未渲染验证（本机未接渲染器），仅检查了语法与节点、分支与正文一致。
