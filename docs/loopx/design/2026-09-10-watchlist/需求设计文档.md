## 二、需求信息

### 2.1 背景

来源：本次对话「存一下想看但是库里面没有的」「只需要存片名」「手动移除片单记录，模块名叫 想看 或者 待下载」。

### 2.2 范围

- AC-W01：顶栏「想看」，片名是唯一用户字段，支持添加、搜索、改名、手动移除。
- AC-W02：重进页面/重启后记录保留；扫描与媒体变化不自动移除记录。
- AC-W03：非法输入与请求失败可见，不丢草稿、不假装写入成功。
- 辅助 lenses：architecture-designer（沿用既有层次）、go-style（薄 App / 服务校验）、sql-style（兼容两后端、参数化查询）。

## 三、概要设计

### 3.1 总述

架构与流程由 [概要设计](概要设计.md) 拥有。

### 3.6 架构一致性

`models/video.go`、`models/media_details.go` 的 Video / CollectionVideo 不满足无文件片名的生命周期；新增模型而不污染媒体语义。复用 `services/person_service.go:normalizeEntityPageLimit`、`escapeSQLLike`、`database/database.go:ApplySchema` 和 `models/schema.go:AllModels`。页面沿用 `DownloadsPage.vue` 的独立导航入口及 `feedback.js:confirmAction`。服务持久状态限于片单表，数据库错误只影响当前操作。测试集中在服务和页面，没有通用抽象或新配置。

## 四、详细设计

### 4.1 片单

**D-W02 · Behavior Contract（AC-W01/03）**：片名前后去空白，1–200 个 Unicode 字符，拒绝控制字符和非法 UTF-8。去首尾空白后片名唯一，区分大小写；新增和改名撞名均返回「该片名已在想看片单中」。数据库唯一索引覆盖并发写入；前端提交期间禁用重复动作。编辑按 ID 更新标题，创建时间不变；移除确认后硬删指定记录。不存在的 ID 返回明确错误。数据库失败保留草稿/列表。

**D-W03 · Interface Contract（AC-W01）**：`ListWatchlist(keyword, cursorID, limit)` 按 ID 倒序，cursor=0 首屏、后续 id < cursor。页大小复用既有默认 50、上限 200，使用 limit+1 判断 has_more 并返回 entries / next_id；不足一页 next_id=0。搜索去首尾空白、最多 200 字符，LOWER(title) LIKE 参数，转义百分号、下划线和反斜杠。`CreateWatchlistEntry(title)` 返回新条目；`UpdateWatchlistEntry(id,title)` / `DeleteWatchlistEntry(id)` 返回 error。

#### 4.1.4 边界条件

空库返回空数组；修改同一条目的并发采用最后成功写入覆盖（只有标题一个字段），更新只执行 UPDATE，不以 Save 复活被删条目；删除与更新以 SQL 实际影响行数为准，不存在即失败，无自动重试。删除并重建使用新 ID。创建同名记录失败，不改变已有条目的 ID、创建时间或输入草稿。前端按查询序号丢弃过时响应，搜索变更清掉旧查询结果；翻页失败保留当前页。

移除当前已加载列表的最后一条时，如果还有下一页，立即加载下一页；只有无下一页且列表为空时才显示空片单。下一页读取失败仍保留加载更多入口及错误提示。

#### 4.1.5 不变行为

视频、作品集、下载、扫描、播放统计和手机接口均不读写片单表。保持现有接口签名。

## 五、存储类设计

**D-W04 · Data Contract（AC-W02）**：`watchlist_entries` 无外键，字段 id 自增主键、title varchar(200) NOT NULL、created_at / updated_at 自动时间戳。主键支持倒序分页；标题唯一索引 `idx_watchlist_title`，无状态/路径/媒体 ID。模型加入 AllModels，沿用两后端 AutoMigrate、备份和双向迁移。新增空表可幂等迁移，不回填已有媒体；老表升级先在事务内规范化首尾空白、归并同名重复项（保留最早 ID 和创建时间），再建立唯一索引，PostgreSQL 在该事务内锁表防止并发旧客户端插入；失败由既有启动错误链路报告。回退应用代码可保留新表；旧版本跨后端迁移不保证复制未知表，不能用于迁移新版本片单。

## 七、接口设计

四个入口仅经桌面 Wails 绑定调用，App 转发给 WatchlistService，无 HTTP 路由。参数与错误契约见 D-W02/03；生成绑定由 Wails 工具生成。
