## 组件

<a id="layout"></a>
### 1 推荐流（D-MW-01、D-MW-02）

- `FeedTopBar`：左侧标签「推荐 · 收藏」（`aria-current` 标当前），右侧范围按钮（文字 = 当前范围名，类型不是「视频和图片」时加「· 视频 / · 图片」）与静音按钮。去掉标题、计数、收藏夹按钮、全屏按钮。
- `FeedDots` 删除；计数文字删除。
- `FeedActionRail`：三个按钮——收藏（`aria-pressed`）、点赞（`aria-pressed`）、更多。按钮 48px 圆形，整块触控 ≥ 44px。
- 新增 `MoreSheet`（`FeedSheet` 上的列表）：个人评分（右侧当前分或「未评分」）→ 评分面板；标签（「N 个」）→ 标签面板；已看过（`role="switch"`，只对视频）；全屏播放（`fullscreenAvailable` 时出现，行为沿用现有 `toggleFullscreen`，iPhone 走 `webkitEnterFullscreen`）；移到废纸篓（危险色，副文案「点了直接移走，可在电脑端回收站恢复」）；取消。
- `FeedMeta`：片名（两行截断）、`类型 · 时长 · 评分 X · 已看`（没有的项不写）、标签行 +「＋ 标签」；「更多标签 ↓」溢出提示保留。

<a id="delete"></a>
### 2 删除（D-MW-03）

- 点「移到废纸篓」：关闭面板 → 调 `deleteItem` → 成功后从历史里移除这一条并前进到下一条（没有下一条就取新的一条）→ 提示「「片名」已移到废纸篓」+ 第二行「要找回，在电脑端「回收站」里恢复」，几秒后自动消失，没有按钮。
- 失败：留在原条目，按 409 三种原因提示（文案沿用现有），其余错误报原因。
- 删除进行中「更多」里的删除项禁用，防止连点。
- `DeleteDialog.vue` 与撤销逻辑（`undoDelete`、toast 上的撤销按钮）删除；`api.js` 的 `restoreItem` 若再无调用方则一并删除（后端接口不动）。

<a id="rating"></a>
### 3 评分（D-MW-04）

- 大号分数（未评分显示「未评分」）；10 颗星，点第 n 颗立即写入 n 分；滑杆 0–10 步长 0.5，拖动时只更新显示，松手（`change`）写入；「清空评分」写 `null`；「完成」关面板。
- 写入失败：显示与分数回到写入前，报原因（沿用现有回滚做法）。

<a id="favorites"></a>
### 4 收藏（D-MW-05）

- 收藏页：顶部标签与推荐页同一组件（「收藏」为当前）+ 刷新按钮；类型分段「全部 · 视频 · 图片」（前端按 `media_kind` 过滤）+「N 个 · 最近收藏在前」；三列 3:4 缩略图墙，视频角标时长。
- 状态：加载中骨架；空「还没有收藏。刷的时候点右侧书签就能收藏」；出错横幅 + 重试，已显示的保留。
- 点一张 → 「在收藏里看」：用墙上当前筛选后的列表、从这一张开始；上下滑在列表内移动，到两端停住（不取新条目）；顶栏「‹ 收藏」+「n / N」+ 静音；右侧三个按钮与「更多」同推荐流。
- 在收藏流里取消收藏：本条留到划走；返回墙时重新取列表。删除：从列表移除并前进。
- 从收藏回到推荐：推荐流的历史与位置不变（两个流各自保存状态）。

<a id="scope"></a>
### 5 范围面板（D-MW-07）与空 / 错误态

- 标题「刷什么」；类型分段三项；五个范围（单选，选中打勾）带条数；`unplayable_count > 0` 时一段说明（文案见设计稿）；切换后关面板并按新范围取一条。
- 空范围：全屏空态「这个范围里没有能播的」+ 原因（有被格式门排除的视频时写明条数）+「换个范围」打开范围面板。
- 取下一条失败：底部错误横幅「没取到下一条」+ 原因 +「重试」，历史保留（现有行为）。

<a id="pin"></a>
### 6 PIN（不改规则）

大标题「输入访问 PIN」+ 说明（在哪设置、30 天免输）+ 密码框（显示 / 隐藏）+「进入」；错误与锁定文案沿用现有（短锁定、每日锁定）。

<a id="visual"></a>
### 7 视觉与守卫（D-MW-06）

- 入口引入 `styles/tokens.css`，根元素套影院表面变量；`short-feed.css` 只用 tokens（颜色、`--fs-*`、间距、圆角、`--z-*`），不再有字面色。
- 移除 `scripts/design-system.test.mjs` 对 `short-feed/` 的目录豁免，守卫保持清零。
- 标签颜色（用户给标签设的颜色）是数据，不算字面色。

### Planning Handoff

- **固定**：两项用户裁定；接口、访问边界、互动回写不变；手势与播放行为不变。
- **下游可定**：组件拆分与命名、提示停留时长、骨架样式。
- **风险**：源码正则断言被顺手放宽（逐条对照表兜底）；手机真机（iPhone Safari、安卓 Chrome）未在本机验证。
