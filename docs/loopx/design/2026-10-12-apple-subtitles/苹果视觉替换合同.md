# 苹果视觉替换合同

2026-10-12；用户已授权替换经验证可行的部分。本合同在实现前记录工程决策。来源：[验证结论](人物与画面检索验证.md)、本轮用户“把这部分替换为苹果的实现”。AI 打标、中文文字搜画面与超分不在本次改动内。

Support lenses: spec、go-style、sql-style。现有所有者为 FaceAnalysisService、SceneIndexService、SceneSearchService；原生调用继续由随包 AppleAI 辅助程序承担。

<a id="D-AV1"></a>
## D-AV1 · Runtime Contract · 已授权范围内的实现决策

复用 AppleAI 打包、可信路径及子进程取消边界，增加 Objective-C Vision 桥。人脸复用现有常驻逐行协议（一次一图、超时关闭进程）；图像特征一次至多 32 张。输入路径必须是本地绝对路径，输出有大小及有限数值校验。系统接口缺失或输出不符合版本明确失败，不安装/调用第三方人脸模型。人脸仅走已经验证的 CPU 路径；私有接口不存在长期兼容保证，设置页说明并提供重新检查。

调用关系（修改后）：FaceAnalysisService → 现有 faceWorkerProcess → AppleAI/Vision；SceneIndexService 与 SceneSearchService → AppleAI/Vision 图像特征。原有 sceneWorkerHost 仅服务中文文字索引/查询，任务调度与状态仍归原服务。旧人脸下载器及 Python worker 退役，磁盘旧缓存不自动删除。

<a id="D-AV2"></a>
## D-AV2 · Data Contract · 人脸记录原位迁移

内部请求固定实测 revision `3737841669`，系统版本不符拒绝使用。新特征为 128 维 float32，带版本前缀存储；旧 512 维不得参与苹果匹配。阈值固定为实测 0.8307785119309815，命名仍需人工确认。原生按短边 25% 灰边检测，坐标反投影为原图左上角相对框；裁剪与方向沿用现有服务。

首次分析及后续重试先用已有裁剪图升级旧观测。以簇为提交单位：锁外提取全部成员，锁内重读成员及旧向量快照，CAS 不符跳过下轮；一笔事务替换观测向量和质心。任何成员缺图、无脸、多脸或提取失败，整个簇保持原状并报告迁移未完成。无簇观测单条迁移。ID、bbox、源指纹、簇归属、人物、忽略时间、观测 UpdatedAt、追加确认/拒绝与关系写入账本不改。无脸标记保持。每张迁移裁剪也经过原有空闲门与共享媒体槽，界面显示迁移进度。取消前已提交的簇可续跑；未提交保持原样。旧候选相似度不再作为当前模型依据，迁移后按现有规则刷新；旧记录仍可查看和人工审阅。

| 起点 | 操作/异常 | 结果 |
| --- | --- | --- |
| 旧簇全部裁剪有效 | 提取、快照复核、事务提交 | 原 ID/审阅决定保留，之后可接纳苹果新观测 |
| 任一裁剪缺失/多脸/失败 | 不提交这一簇 | 保留全部旧数据；本轮状态显示未迁移数量 |
| 提取期间审阅改变成员 | 快照不相等 | 不覆盖审阅结果；下轮重试 |
| 新媒体 | 苹果检测/聚类 | 只产生候选，已命名簇追加仍待确认 |

<a id="D-AV3"></a>
## D-AV3 · Data / Behavior Contract · 独立的以图索引

复用 scene_visual_segments 的 model_id 隔离苹果 768 维 float32 特征；欧氏距离转为单调分数 1/(1+distance)，不使用 CLIP 点积或 0.92 合段阈值。苹果每个采样帧独立成段，查询结果沿用相邻命中合并与来源 ±10 秒排除。抽帧保持宽高比，长边不超过 640。

原 scene_index_states 主键只有 video_id，不能存两套状态。新增同形 scene_image_index_states（video_id 主键、指向 videos 级联外键），由同一个 SceneIndexService 写入；这只是现有索引的第二种派生表示，不是新任务/服务。每模型写入、失败和旧索引清理只影响所属表示；旧 CLIP 索引保留。双后端迁移清单与夹具增加该表。苹果索引初始为空，页面在以图模式用现有“建立索引”入口传 provider=apple，可在没有 Python/CLIP 时独立建立；文字模式仍用已保存文字提供方。覆盖率分别展示，不把旧 CLIP 覆盖率当苹果覆盖率。

| 共用输入 | 独立路径 | 持久结果/查询 |
| --- | --- | --- |
| 视频及现有采样间隔 | 苹果 Vision、保持宽高比 | Apple 模型段 + image 状态；上传图片或当前帧查询 |
| 视频及现有采样间隔 | 现有 CLIP / 外部描述 | 原模型段 + 原状态；中文文字查询保持 |

## 实现与验证记录

- 生产辅助程序固定人脸内部 revision `3737841669`（`0xdecaf005`），并校验响应模型标识；padding 使用 ties-to-even，与调研脚本的 `round` 一致。新向量带版本前缀，旧2048字节向量仅供迁移识别，不参与新匹配。
- 生产人脸组件实测1400张公开LFW照片。复用调研的独立测试身份与固定阈值，参考库120人240图：已知160次查询正确接受155、拒绝5、错认0；未知200次查询误接纳0。按相同基准协议取最大人脸，未以多脸数量排除样本。原始统计：[人脸](validation/metrics/production-face-metrics.json)。这不是自然视频跟踪准确率。
- 生产图像特征实测100张COCO参考图，各100张压缩、中心裁剪、视频编解码查询，三组top1均100/100：[画面统计](validation/metrics/production-scene-metrics.json)。与中文文字检索无关。
- `TestAppleVisionNativeIntegration` 显式提供公开照片，执行真实人脸提取→坐标裁剪→再次提取（最终构建余弦0.987111），以及FFmpeg生成视频→苹果索引→图片检索命中；没有准备CLIP运行时。
- 新增回归：簇迁移成功/缺图/多脸/取消/并发移除、命名与忽略及追加状态/时间保留、重复执行；共享槽等待取消及空闲门；模型版本与阈值；文字/苹果索引并存、重建及失败隔离；欧氏排序。隔离副本内4个手工变异（时间、快照、距离、模型隔离）全部被相应测试捕获，源文件哈希未改变：[变异统计](validation/metrics/production-mutation-results.json)。
- 独立代码审查两轮；首轮发现观测时间及迁移调度问题，已修复并补回归，复核无剩余Critical/Important。
- 双后端迁移清单加入图片索引状态表，SQLite全表迁移及往返夹具通过。尝试启动本机独立PostgreSQL测试实例失败：现有libpq包含initdb/pg_ctl却缺少postgres服务端，故**本轮未实测PostgreSQL**，未安装额外服务。
- 升级只有增加派生表和按簇更新特征，不删除人工数据。已迁移特征不能交给旧InsightFace版本比较；回退旧应用需使用迁移前备份或明确重新分析，不能将苹果字节解释为旧向量。本次未操作用户库、未安装应用、未提交或推送。
