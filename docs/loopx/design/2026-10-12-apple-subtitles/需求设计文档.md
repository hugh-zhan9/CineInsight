# 苹果系统字幕 · 实现合同

来源：[需求](../../../../.loopx/intake/2026-10-12-apple-subtitles/requirements.md)、[概要](概要设计.md)。状态：已实现并构建，独立复审通过；未安装/部署。Support lenses：architecture-designer（复用现有 owner/子进程隔离）、go-style（上下文、错误及并发生命周期）。

## 接入与协议

辅助程序使用一请求一进程 JSON 协议：状态/语种列表、准备识别语言、转写/检测语言、翻译/准备翻译语言。标准输出只返回协议结果，日志不含音频、字幕或路径。Go 只运行可信的随包可执行文件（开发构建使用项目产物），不接受用户提供的任意可执行路径。请求经 stdin，输出有界，取消终止并等待子进程。

辅助程序不写 SRT；转写返回语言和时间片段，Go 复用 `subtitleparser.Segment` 与现有 pending 写回。词级时间用于按标点/时长/字符数整理字幕，禁止零时长和逆序片段。自动检测仅推测已安装语种，候选按语言去重而非遍历全部地区变体，低置信度/语言不一致不选。

翻译返回各条 `clientIdentifier`，桥接按 ID 恢复原顺序并校验缺失、重复及越界，保持空译文处理、批处理/末批、双语合并和写入器语义。已有文本源语言可由系统 NaturalLanguage 推测；短/混合/不明确输入明确报错可改语言。准备翻译使用系统 SwiftUI 下载授权界面，正常后台调用使用 `TranslationSession(installedSource:target:)`。

## 迁移与复用

- 字幕引擎收为 `apple`，配置与界面移除 WhisperX/Qwen/外部翻译 provider、模型/API Key及术语入口。历史术语数据与数据库迁移链保留。
- WhisperX 文件中的共享 Python 安装工具仍被人脸/场景运行时使用，移到中性共享文件，不误删其他链路依赖。
- 旧任务的强制完成复用现有 pending 文件；重试不运行旧引擎。旧源语言为 auto 可走系统推测，手动语言沿用有效映射。
- 字幕服务的队列与写回仍是唯一 owner；不新增任务表、通用 AI 服务或另一份状态存储。
- 构建脚本先编译原生 helper，再随 Wails 包携带；源代码不在最终用户机器编译，缺失打包组件时明确不可用。

## 系统能力验证（2026-10-12）

本机 M5 / 16 GiB / macOS 27.0，Command Line Tools 的 macOS 26.5 SDK。新版本 Xcode 虽已安装但许可未接受，本轮没有替用户接受许可或切换全局开发目录。

| 能力 | 官方接口与本机证据 | 替换结论 |
|---|---|---|
| 语音识别 | SpeechTranscriber 中英语音、词级时间戳成功；错误语种会产生拼音式错误，因此用多候选+转写置信度+文字语种一致性建议。可重复探测 `scripts/test_apple_ai.py` | 实施替换；自动检测仅在已准备语种内，开头 30 秒不足以判断时手选 |
| 翻译 | TranslationSession 已安装语言模式中英双向成功；独立 helper 的 SwiftUI 准备入口对已有中英资源成功结束，未触发新下载 | 实施替换；新语言首次下载授权/取消的系统 UI 尚未进行真实下载验收 |
| 人物识别 | [Vision](https://developer.apple.com/documentation/vision) 公共接口有脸框/关键点/质量，但没有找到与当前 InsightFace 身份向量及跨媒体人物聚类等价的公开接口 | 保留当前实现；检测到脸不等于知道是否同一个人 |
| 画面检索 | [Feature Print](https://developer.apple.com/documentation/vision/analyzing-image-similarity-with-feature-print) 支持图像之间相似度，不能直接替代当前 Chinese-CLIP 的文字/图像共同向量空间 | 保留；不能用仅图搜图能力取代中文描述搜镜头，也不能混用旧索引向量 |
| AI 打标 | 最新[多模态接口](https://developer.apple.com/documentation/foundationmodels/analyzing-images-with-multimodal-prompting)允许系统模型理解图片；本机 SystemLanguageModel 返回 deviceNotEligible，未定位原因，也未验证当前自定义闭集/多帧 Agent 合同 | 有技术方向，尚不满足本机替换依据；保留当前实现 |
| 超分 | [VideoToolbox 系统超分](https://developer.apple.com/documentation/videotoolbox/vtsuperresolutionscalerconfiguration) 本机 isSupported=true，倍率仅 4；640×360、1280×720、1920×1080 视频配置成功，1080×1920 和2560×1440拒绝。模型状态 downloadRequired，未下载，未处理真实画面 | 不能等价替换现有两倍 general/anime 方案；仍需资源准备、倍率/竖屏边界和真实视频画质验证 |

原生语音/翻译并不要求 SystemLanguageModel 可用。[Speech 资源](https://developer.apple.com/documentation/speech/assetinventory)与[翻译资源](https://developer.apple.com/documentation/translation/translationsession/init(installedsource:target:))由系统管理；「无需第三方模型」不代表所有苹果语言资源预装。

初次独立审查发现：旧任务重试的持久引擎未同步、连续检测取消状态残留、退出未等待语言准备，以及旧准备结果覆盖新弹窗。均已补回归并修正，最终只读复审未发现新的 Critical/Important，确认四项均已闭合。探测只用合成短音频与少量文本，不能声称整部影片准确率或超分画质已经通过。
