# 苹果系统字幕 · 概要设计

状态：2026-10-12 按用户裁决完成实现与构建，独立复审通过；未提交、安装或部署。测试与原生质量边界见详细合同。
来源：[用户需求与场景](../../../../.loopx/intake/2026-10-12-apple-subtitles/requirements.md)。详细合同见[需求设计文档](需求设计文档.md)。

## 核心方案

<a id="D-001"></a>
**D-001 · Architecture/Operational Contract（AC-01/03/05）**：字幕服务仍拥有任务、字幕文件、数据库和取消。随应用打包 Swift 原生辅助程序，按请求调用 Speech/Translation/NaturalLanguage；请求及结果通过标准输入输出传递，不启动网络服务器，不携带第三方 AI 模型，不自行读写媒体库。每次调用由 Go 上下文管理子进程。原生辅助程序不接管任务或创建第二份字幕状态。

架构视图（箭头为调用，新增原生桥替代字幕第三方引擎）：

```text
Vue 字幕/设置/工作台 → Wails App → SubtitleService（队列、备份、写回）
                                      ├→ FFmpeg（本地音频提取，保留）
                                      └→ Swift 系统辅助程序（新增）
                                            ├→ Speech + NaturalLanguage
                                            └→ Translation
```

依据：现有 `transcribeVideoLocally` 集中分派识别、`SubtitleTranslator` 隔离翻译，子进程也是现有运行方式。直接引入 Swift 进 Go 主进程会增加 Swift 并发/UI生命周期与 Wails 的耦合；辅助程序保留可取消的进程隔离，只增加一个随包构建产物。

<a id="D-002"></a>
**D-002 · Behavior Contract（AC-02）**：手选语种直接识别；自动模式只对系统已安装且支持的不同语言候选做短音频识别，结合文字语言一致性和转写置信度推测，结果显示给用户且可修改。自动模式是有边界的建议，不保证识别所有未准备的语言；不确定时报错要求手选，不静默输出猜测语种的完整字幕。语言检测与正式识别共享既有串行槽。后台 AI 临时转写同样只用已准备的系统资源，不自动安装。

<a id="D-003"></a>
**D-003 · Behavior/Data Contract（AC-01/03/04）**：系统翻译替代原翻译器，保持字幕条目和时间轴一一对应；取消与失败沿用已有文件保护。移除术语表入口及注入路径，历史表和数据保留。旧翻译配置不再用于请求，不自动清理用户磁盘模型缓存。

<a id="D-004"></a>
**D-004 · Compatibility Contract（AC-03/05）**：原生功能要求 macOS 26+ 且系统能力可用；不支持平台明确不可用，不保留第三方引擎回退。已生成 `.srt` 的读取、编辑、搜索不受平台能力影响。历史待确认临时文件仍可完成/放弃；需要重新识别的旧引擎任务改用系统入口，不能重新执行第三方引擎。

## 其他 AI 能力

<a id="D-005"></a>
**D-005 · Scope Contract（AC-06）**：人物身份聚类、跨模态画面检索、自定义闭集 AI 打标、超分先验证后替换，不因存在相近名称的系统 API 就认定等价。初步证据：Vision 有检测/分类/图像相似度，未证明身份聚类与文本图像共同向量空间；最新 Foundation Models 有多模态接口但本机模型不可用；VideoToolbox 超分本机支持 4×，要求系统模型下载，输入尺寸有约束，未完成画质验证。保留现有实现。

## 保护与验收

复用字幕任务队列、写锁、备份、pending 产物及双语合并。新原生调用失败仅失败本次字幕工作，不绕过任务状态或写入器。系统语言包首次准备由用户显式操作触发。

文档推演：已安装中英语种可直接识别/翻译；未安装语种先准备；无匹配语言和低置信度停止识别；翻译失败不写原字幕；旧 pending 不依赖原引擎再次运行。独立复审未发现 Critical/Important 问题；集成验证见详细合同末节。
