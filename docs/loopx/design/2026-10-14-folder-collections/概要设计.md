# 建议作品集看文件夹 · 设计

状态：已实施（2026-10-14）。Accepted——用户 2026-10-14 同意：同一个文件夹里的视频可以当一个作品集来建议，嵌套文件夹也要能处理。
来源：用户问「同一个文件夹下的视频能不能当成一个作品集」。原规则 D-023 只看文件名、不看目录名。
相关：建议作品集（AI-CONTEXT §2.22，D-023..D-025、D-PC38）；实现在 `services/collection_suggestion_folders.go`（纯函数）与 `collection_suggestion_service.go`（接入）。

## 三项决定

1. **D-023 修订：文件夹结构与文件名一起判断。** 先按文件夹成组；被文件夹候选收下的视频不再参与按文件名的分组，其余视频照旧按文件名规则成组。
2. **只给建议。** 结果和以前一样只是待审阅候选，分析不建作品集、不改标题和文件名。
3. **人物名文件夹不提。** 文件夹名（原样或收拾后）与某个人物的显示名或原名相同（`normalizeLocalMetadataName` 后比较）就不当作品集；它下面的子文件夹照常判断。人物没有单独的别名表，原名就是别名。

## 规则（自底向上，逐个文件夹）

- **章节子目录并入上级**：`第N周/章/季/部/期/节/课/篇/卷/单元/模块`（另含 讲/天/阶段；N 可以是数字或中文数字，后面可接说明文字，如「第十三周Go语言实践Runtime」），`Season N`、`S01`、`Part N`、`Disc N`、`CD N`、`Vol N`（另含 chapter/week/lesson/module/unit），以及纯 1–3 位序号（`01`）。整棵子树并入上级，带上章节号。章节目录自己永远不成候选；上级不能成候选（扫描根、无意义名、人物名）时，这些视频留给文件名规则。
- **发布包装透明**：整棵子树只有一个视频的非章节子目录，把这个视频上提为上级的成员。`sample(s)`、`trash`、回收站和隐藏目录（`.` `@` `$` `#` 开头）里的单个视频不上提。
- **成候选的条件**：不是扫描根；名字有意义、不是人物；成员 ≥ `folderSuggestionMinMembers`(2)；并且满足其一：
  - (a) 有章节子目录；
  - (b) 文件像同一系列：过半文件解析出同一个系列名，或过半文件以序号开头且序号不止一个，或全部文件名有至少 `folderSuggestionCommonPrefixMinRunes`(3) 个字的公共前缀；
  - (c) 没有子候选，且成员不超过 `folderSuggestionMaxLooseMembers`(100)。
- **分类容器**：有 ≥ `folderSuggestionContainerChildren`(2) 个非章节子文件夹各自成了候选，这个文件夹自己不成候选；它散放的文件留给文件名规则。
- **无意义的名字**（不成候选、不当名字）：新建文件夹 / New Folder / untitled folder / trash / 回收站 / 归档 / archive / temp / tmp / 下载 / Downloads / 未分类 / misc / 其他 / sample(s)，含副本编号（「新建文件夹 (2)」「New Folder 2」）；通用分类名（电影、视频、电视剧、剧集、动漫、综艺、纪录片、直播、movies、videos、tv、anime 等）；纯日期/数字（`2021`、`2021-12-04`、`20211204`）；自动生成的名字（`From-Telegram-20211204T015145791Z`）；收拾后什么都不剩的名字。

## 名称、记忆键与顺序

- **名称**：文件夹名去 `[…]` `【…】` 来源括号（整个名字都在括号里时保留内容），在 `SxxExx`/`Sxx`/`Season N`/`第N季`/年份/第一个质量标签处截断（取最靠前且前面还剩名字的一处），`.` `_` 换空格。`Immortal.Doctor.In.Modern.City.S01.1080p.iQIYI.WEB-DL.AAC2.0.H.264-MWeb` → `Immortal Doctor In Modern City`。章节合并用上级的名字。超过 200 字节按字符边界截断。
- **记忆键**：`normalized_series = "dir:" + 小写的相对扫描根路径`。超过 200 字节时截断并接 `#` + 16 位 sha256，结果确定。忽略键沿用 `sha256(扫描根 + "\n" + normalized_series)`，因此按文件夹记住忽略，文件夹里新增一集也不再提。不改表结构。
- **同名合并**：同一扫描根下收拾后名字相同（忽略大小写）的候选文件夹，在同一父目录下、或名字里都带季号（`Show.S01…` 与 `Show.S02…`）时合并成一组，按季号排；记忆键取排在最前的文件夹。只是同名、位置不同又没有季号的（`A/Extras`、`B/Extras`）各自成组。
- **顺序**：文件夹季号 → 章节号（本层散放的文件排在章节前）→ 文件名解析出的季/集 → 相对路径自然排序（数字按数值，「第十一」当 11）。
- **季/集与位置**：有章节时 Season = 章节号，否则取文件名解析的季，合并分季目录时取文件夹季号；Episode = 文件名解析的集号，否则取文件名开头 1–3 位序号。位置是稠密排名，只有文件名解析出同一系列同一集的才共用（同集多版本）；只靠开头序号认出的集号不共用。剔除已入集成员后重新压成稠密排名。

## 接入与界面

- `analyzeOnce` 分页读完视频后按扫描根调用 `buildFolderSuggestionGroups`，人物名每轮读一次。之后的忽略键过滤、追加候选（`splitSuggestionMembers`）、指纹与 `persistCandidates` 不变；文件夹候选跳过按集号重排。`Matched` 另计被文件夹候选收下、但文件名没解析出剧集的视频。
- 同一批成员（同指纹）的待审阅候选换了成组依据时，`persistCandidates` 同时改写 `normalized_series` 并重写成员的季/集/位置。
- `CollectionSuggestionView` 新增 `basis`（`folder` | `filename`，看 `dir:` 前缀）与 `folder`（成员的共同目录，相对扫描根；就是扫描根时为空）。面板对文件夹候选显示一行「按文件夹：<folder>」，`folder` 为空时显示扫描根；其余不变。

## 已知局限

- 带序号加说明的章节目录（`01-基础篇/`）不算章节，会各自成候选，上级变成容器。
- 合并在扫描根下的分季目录，「按文件夹」一行只能显示扫描根。
- 面板空态与进度文案仍写「按文件名」。
