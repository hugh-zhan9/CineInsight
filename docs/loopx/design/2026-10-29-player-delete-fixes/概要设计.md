# 播放与删除体验修正

来源：2026-10-29 用户确认“刚打开播放就停在片尾”；要求记住“同时把原文件移到废纸篓”的上次选择、图片删除确认居前；指出播放器仍有两个最大化按钮，应用内全屏与全屏未落实。基线9769196；本批不包含提交、推送或安装。

<a id="D-RESUME-01"></a>
## D-RESUME-01 起播边界
普通续播以媒体元数据的实际时长再次应用现有片尾判定（5%，最多180秒）；片尾或超范围断点从0起播，保留有效中途断点。不将错误断点夹到片尾。字幕/书签等显式指定时间仍按原规则夹到实际时长内；不改已存观看事实和外部播放器协议。

<a id="D-PREF-01"></a>
## D-PREF-01 删除选择记忆
用户上次确认删除时的复选框选择，写入既有Settings.delete_original_file，图片与视频共用且重启后保留；取消不修改。已有“删除前确认”开关语义不变，人物/详情删除仍先确认。设置持久化由SettingsService单字段更新，不用整份旧设置覆盖其他字段，不另设localStorage副本。删除动作不因偏好保存失败而更改后果；保存失败明确提示，删除仍按本次确认的值执行。

新增只写这个字段的桥接调用，成功事件只同步App已有settings快照。公共确认框、图片管理单张/批量和共享单媒体删除都调用同一记忆函数。

<a id="D-MODAL-01"></a>
## D-MODAL-01 确认层顺序
共享单媒体删除的确认Teleport每次打开重新建立，追加到body最末；撤销/进度宿主单独保留。不靠无限提高z-index掩盖旧堆叠容器。视觉顺序、Esc层栈及焦点同为最后打开者优先；新图片查看器晚于上一轮撤销宿主打开时也正确。

<a id="D-FULL-01"></a>
## D-FULL-01 单入口双模式全屏
原生video controls在实际WebKit无法可靠只隐藏某一个按钮，改为共享PlaybackControls：暂停/播放、单一进度条、时间、音量和唯一全屏入口。入口提供“应用内全屏”（HTML dialog top layer铺满当前应用窗口）与“系统全屏”（对内部播放器surface调用Fullscreen API），活动时点击入口退出。两种模式保留同一video节点、播放位置、字幕及观看会话，不换源。Esc退出最上层播放器全屏，不关闭下方抽屉。

应用内全屏外壳使用始终存在的非模态open dialog，showModal进入窗口内顶层、退出恢复inline；系统全屏作用于内层播放器surface，避免对dialog调用Fullscreen API。无API时明确显示不支持，不伪报成功或另加回退。播放器键盘规则沿用现有入口；详情/抽屉与队列共用控制条，不新增播放状态来源。

<a id="D-PLAYER-UI-01"></a>
## D-PLAYER-UI-01 控制层与视觉修订（2026-10-30）
用户指出两条滑条与画面脱节，要求参考优秀开源播放器UI。本次技术选择Media Chrome 4.19.4（MIT）替代自写的播放、时间线与时间显示控件；它包装现有原生video，不接管Go会话、播放代理、统计或源校验。采用该库的控制层而非替换播放引擎，减少对现有字幕与队列生命周期的影响。依赖随应用打包，不引入CDN或新持久化来源。Support lenses: none。

画面铺满播放器，底部渐变浮层内只常驻一条播放时间线；音量与字幕开关、偏移及刷新按需展开，唯一全屏入口仍提供两种模式。暂停时控件可见，播放中空闲自动隐藏；键盘保留原左右5秒、上下5%及空格规则。关闭库的键盘、手势及音量/静音/字幕偏好，避免重复事件与状态冲突。字幕继续由现有组件生成track，按照控制条高度移动cue位置，控制条隐藏时回到画面底部；不再缩小视频画布。seek预览复用现有sprite，只放入库的时间线预览槽。

所有媒体事件仍由原宿主上报；切全屏、音量和字幕设置不能换video或source、重置进度或队列token。队列的非模态dialog使用正常文档流相对定位，宽度由父容器约束，避免浏览器默认绝对定位越界。设置弹层留在当前播放器子树，以便两种全屏可操作；Esc先关闭设置层，再退出全屏。无字幕、读取失败和全屏拒绝继续显示现有明确状态。原D-RESUME/PREF/MODAL不变。

验证以组件回归保护身份、错误及全屏生命周期，并用实际WKWebView视频验证库控件播放/seek/音量、键盘、两种全屏、字幕避让和窄布局；jsdom不模拟第三方控件内部实现。样式核验需要实际截图，边界数值不能代替视觉检查。

参考：[官方接入](https://www.media-chrome.org/docs/en/get-started)、[控制器](https://www.media-chrome.org/docs/en/components/media-controller)、[控件布局](https://www.media-chrome.org/docs/en/position-controls)。
