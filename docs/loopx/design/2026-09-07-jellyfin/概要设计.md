# Jellyfin 兼容入口复用当前片库

2026-09-07；范围已由用户确认。实现以本目录详细设计为准。

Fileball → 独立局域网 HTTP 入口（密码登录、令牌鉴权）→ services 的片库查询/状态服务 → 当前数据库及本地媒体。App 只负责配置和启停。

独立端口默认 8096，冲突明确报错，不选备用端口。不能直接挂短视频匿名服务：它默认运行且无登录，并对格式/时长和反馈投影有专用语义。复用 `shortFeedRemoteAllowed` 的网络来源判定和 `http.ServeContent` 的 Range 能力，不复用匿名 HTTP 路由及 Feed 的媒体筛选。

认证配置仍属于 Settings；Jellyfin 会话属于兼容服务器，只驻留进程内；视频、标签、作品集和观看状态均不复制。关闭/改配置会断开当前连接并清除令牌；桌面程序退出或休眠时客户端不能播放。

HTTP 路由与 JSON 映射在 `services/jellyfin_*.go`；筛选复用 `applyLibraryFilter`，写状态调用 `VideoService`。HTTP 请求不运行桌面播放器、不扫描全盘、不生成代理、不删除媒体。新入口可通过删除 App 接线与兼容文件移除，Settings 遗留列无副作用。

备选：另装 Jellyfin 会形成独立观看状态；WebDAV 无法表达这些视图；扩展匿名短视频入口会混合不同信任边界。接受独立监听器的维护成本换取独立启停与鉴权。

裁决映射：网络/身份/配置边界→详细设计 D-01；查询/实体所有权→D-02；播放和用户状态→D-03；手机 UI→D-04。锚点详细定义唯一保留在详细设计，不在概要重复定义。
